# Plan Protocol (legacy alias)

**Use [hierarchical-plan-protocol.md](hierarchical-plan-protocol.md)** — default for all `/goal` commands.

Flat `## Plan` checklist in GOAL.md is deprecated. Use:

- **Master Plan** table in GOAL.md
- **Phase plans** in `goals/{id}/phases/phase-N.md`

Single-level planning only if objective has one milestone (master plan = 1 phase).
