# Chapter 10: Когда лучше публиковать

## Core Idea
Время публикации даёт статистический разброс (~20% по суткам, ~39% по неделе), но тема и жанр важнее слота; пятничный вечер — пик развлекательного контента.

## Frameworks Introduced
- **Суточный цикл**: рост просмотров с ночи к вечеру (МСК)
- **Недельный цикл**: рост чт–вс; вт–ср — минимум
- **Конкуренция за ленту**: пик публикаций 11–18 в будни

## Key Concepts
- **Гистограммы Cloud4Y / @DmitrySpb79**: средние просмотры по интервалам; данные 2016–2019 + частично 2021
- **Пятница вечером**: много лёгкого контента — серьёзная рабочая статья может проиграть
- **Выходные vs будни**: разное распределение публикаций и чтений

## Mental Models
- Use timing as tie-breaker, not главный рычаг
- Think of пятничный вечер как слот для лёгкого/развлекательного
- Use собственную аналитику (Метрика/GA в корпблоге) поверх общих гистограмм

## Anti-patterns
- **Ожидание «магического часа»** вместо работы над темой
- **Публикация серьёзного материала** в пик развлекательного трафика

## Key Takeaways
1. Тема > время публикации
2. Вечер и выходные статистически сильнее
3. Учитывайте объём конкурирующих публикаций в ленте
4. Для компаний — согласовать с контент-планом, не только с часами
