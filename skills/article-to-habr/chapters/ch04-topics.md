# Chapter 4: Где брать хитовые темы и как с ними работать

## Core Idea
~80% успеха — тема: она должна быть уникальной и полезной (практически или как инфотейнмент); жанр усиливает охват.

## Frameworks Introduced
- **Правило 80%**: тема доминирует над оформлением
- **Уникальность + полезность**: новый угол или факт + ценность для читателя
- **Хитовые жанры**: расследование, разоблачение, социальное, DIY, наболевшее, «как устроено», личный опыт, гиковское
- **Драйв-лист**: личный список «горящих» тем
- **Типы авторов**: Specialist, Cross trainer, Survivor, The called

## Key Concepts
- **Инфотейнмент**: чтение ради интереса без практической пользы (пример Bugatti Veyron)
- **Социальное**: несправедливость, HR, релокации — эмоции → оценки
- **Разоблачение**: массовый обман продуктов/характеристик
- **Расследование**: сюжет + раскрытие неизвестных фактов
- **Источники тем**: аналитика, экспертиза, опенсорс, кейсы, переводы, конференции, мнения по новостям

## Mental Models
- Use жанр осознанно — адаптируйте угол, не выдумывайте факты
- Think of нишу как защиту — «занять поляну» лучше, чем конкурировать в общем потоке
- Use драйв-лист вместо ожидания вдохновения

## Anti-patterns
- **Социальное без фактов**: раздутые обвинения → антирекорды (пример с беспилотником Яндекса, –69)
- **Копирование топа без новизны**
- **Фокус только на «гениальных техниках»** вместо системной работы с темами

## Worked Example
Разоблачение «Светодиодное вранье»: тест ламп → заявленные 11 Вт / 720 лм недостижимы на рынке → +363, 255k просмотров. Уникальность: системная ложь индустрии, не один бренд.

## Key Takeaways
1. Тема ≈ 80% успеха
2. Расследование и разоблачение стабильно в топе жанров
3. Уникальность = то, что до вас не обсуждали открыто
4. Ведите драйв-лист
5. Не обязательно быть супер-экспертом — есть роли Survivor, Cross trainer
6. Занимайте нишу, если направление непопулярно
