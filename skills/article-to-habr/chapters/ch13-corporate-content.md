# Chapter 13: Как компании писать про себя и продукты

## Core Idea
Корпоративный контент работает через кейсы, экскурсии, продуктовые истории с пользой и честностью — не через прямую рекламу.

## Frameworks Introduced
- **Типы корпоративных публикаций**: кейсы, экскурсия по офису, продукт, анонсы мероприятий, прочее
- **Мотивация сотрудников писать**: внутренние стимулы и процессы

## Key Concepts
- **Кейс**: проблема → решение → результат с цифрами
- **Экскурсия по офису**: человеческое лицо компании без стока
- **Продукт**: показывать ограничения и сравнения, не только плюсы
- **Анонсы**: ценность для читателя, не пресс-релиз ради галочки

## Mental Models
- Use сотрудника-автора для аутентичности Survivor/Specialist
- Think of продуктовый пост как гайд/кейс, не брошюру
- Use мотивацию через признание, время в рабочих часах, редакторскую помощь

## Anti-patterns
- **Хвалебный обзор** без недостатков и альтернатив
- **Пресс-релизным языком** на Habr
- **Заставлять писать** без поддержки редактора

## Key Takeaways
1. Кейсы с цифрами — базовый формат корпблога
2. Продукт — через пользу и честные ограничения
3. Мотивация сотрудников требует процесса, не приказа
4. Разнообразие форматов снижает усталость аудитории
