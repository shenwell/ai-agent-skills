# Chapter 5: Работа с текстом

## Core Idea
Текст строится по Mainpointschema: сначала инфополе, главное, формат, заголовок и структура — только потом написание; лид и финальный заголовок — в конце.

## Frameworks Introduced
- **Mainpointschema (8 шагов)**: инфополе → главное → формат → заголовок → структура → фактура → написание → сокращение/вычитка/лид
- **Форматы**: гайд, обзор, кейс, энциклопедический, байка
- **Подзаголовок-вывод**: H2/H3 = факт или вывод фрагмента

## Key Concepts
- **Информационное поле**: что уже публиковалось — избегать дублей
- **Главное для читателя**: не «про что я хочу», а «что получит после прочтения»
- **Рабочий заголовок**: до текста; без него тема расползается
- **Структуры форматов**:
  - Гайд: проблема → подготовка → шаги → подводные камни → итоги
  - Обзор: интересное в начале, далее по убыванию
  - Кейс: проблема → как было → что сделали → результат
  - Энциклопедический: описание → история → параметры → ссылки
- **Байка**: история в начале (пример контрафактных HDD)
- **Финальные аккорды**: дать полежать → вычитка → лид → уточнить заголовок

## Mental Models
- Use каркас до «мяса» — структура вторая после заголовка
- Think of подзаголовок как микро-заголовок для скроллеров
- Use байку для эмпатии, затем технические детали

## Anti-patterns
- **Шаблонные подзаголовки**: «Упаковка», «Экран», «Камера»
- **Художественные подзаголовки без расшифровки**
- **Начинать писать без формата и заголовка**
- **Интервью как формат** без согласованной структуры (проблема интервью)

## Worked Example
Байка про контрафактные HDD: личная покупка → подозрение → проверка → технические детали подделок. Читатель узнаёт ситуацию, остаётся за деталями.

## Key Takeaways
1. Шаги 1–6 до первого абзаца текста
2. Заголовок и структура — обязательные якоря
3. Подзаголовок = вывод/факт
4. Лид пишется последним
5. Объём и глубина — под задачу читателя, не «на всякий случай»
6. Онлайн-сервисы проверки текста — на этапе вычитки
