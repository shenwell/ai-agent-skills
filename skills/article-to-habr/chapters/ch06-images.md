# Chapter 6: Работа с изображениями

## Core Idea
Идея и текст уникальны; изображения — свои. Иллюстрация дополняет смысл, а не «разбавляет»; фотосток с «успешным успехом» подрывает доверие.

## Frameworks Introduced
- **Иллюстрация vs разбавление**: картинка несёт факт или параллельный сюжет
- **Технический рецепт фото**: свет + композиция + цвет (насыщенность, кривые)
- **Правило третей**: ключевые объекты на пересечениях линий

## Key Concepts
- **Анти-фотосток**: глянец, улыбающиеся люди в переговорке = маркетинговый душок
- **Свет**: много качественного света; лайткуб для предметки; ~6500 K
- **JPG vs PNG**: по задаче (фото vs схемы)
- **Авторские права**: источники бесплатных изображений, водяные знаки
- **Съёмка людей**: согласие и контекст

## Mental Models
- Use своё фото рабочего места вместо стока — доверие выше
- Think of подпись к иллюстрации как вторую строку фактов
- Use параллельный сюжет в картинке (пример: шиповка резины + фото инструмента для ошиповки)

## Anti-patterns
- **Картинки «для красоты»** без связи с текстом
- **Фотосток для «разбавления»** — три сигнала: фальшь, маркетинг, «уже видел»
- **Мутные, грязные снимки**

## Key Takeaways
1. Свои изображения предпочтительнее стока
2. Иллюстрация = пояснение, не декор
3. Свет и композиция важнее дорогой камеры
4. Подпись к картинке — дополнительная информация
5. Для «разбивки» текста без картинок — см. юзабилити (Ch 7)
