# Chapter 7: Аналитика и юзабилити текстов

## Core Idea
Читатели скроллят и ищут «зацепки»; метрики доскрола и прочтений показывают, где текст «рвётся»; оформление напрямую влияет на дочитывание.

## Frameworks Introduced
- **Воронка чтения**: потери >10% на участке — сигнал (ошибки, несоответствие заголовку, слабое оформление)
- **Метрики Habr**: доскрол 60%+ (отлично 85%+), прочтения ~30–35%

## Key Concepts
- **F-pattern / скроллинг**: читают выборочно, не линейно
- **Элементы оформления**: подзаголовки с выводом, списки, цитаты, врезки, иллюстрации с подписями
- **Главное правило**: ни одного экрана голого текста

## Mental Models
- Use подзаголовок как якорь для скроллера
- Think of каждый экран как мини-лендинг — должен быть визуальный вход
- Use цитату для главной мысли абзаца

## Anti-patterns
- **Стена текста** без структуры
- **Подписи «Рис. 1»** без смысловой нагрузки
- **Игнор метрик** после публикации

## Key Takeaways
1. Доскрол 60%+ — ориентир качества структуры
2. Потери >10% на блоке — расследовать причину
3. Подзаголовки, списки, цитаты, картинки — обязательный минимум
4. Хитовый рейтинг без юзабилити может дать низкие прочтения
