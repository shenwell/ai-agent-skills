# Чек-лист перед публикацией статьи

## Перед написанием
- [ ] Изучено информационное поле по теме
- [ ] Выделено главное для читателя (не «про что я хочу»)
- [ ] Выбран формат (гайд, кейс, обзор и т.д.)
- [ ] Сформулирован рабочий заголовок
- [ ] Создана структура по формату

## Заголовок и лид
- [ ] Заголовок 7-8 слов (до 15 макс)
- [ ] Соответствует тексту на 100%
- [ ] Есть польза, детали, ключевые слова
- [ ] Лид написан после текста, не дублирует заголовок

## Оформление
- [ ] Нет экранов голого текста
- [ ] Подзаголовки — выводы/факты, не шаблонные
- [ ] Иллюстрации с подписями
- [ ] Главные мысли выделены цитатами

## Перед публикацией
- [ ] Фактчекинг: даты, имена, цитаты, термины
- [ ] Проверка матчасти
- [ ] Ответ на вопрос: «К чему придерётся читатель?»
