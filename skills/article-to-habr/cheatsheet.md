# Шпаргалка: статьи на Habr

## Выбор темы

| Ситуация | Действие |
|----------|----------|
| Нужен максимальный охват | Проверить жанр: расследование, разоблачение, социальное |
| Тема «избита» | Искать уникальный угол: новая проблема, неожиданный факт, лёгкое решение vs сложное |
| Непопулярное направление | Занять нишу; писать как Specialist / Survivor / Cross trainer |
| Нет идей | Вести драйв-лист; смотреть конференции, опенсорс, кейсы, переводы |

**Правило:** тема ≈ 80% успеха. Оформление важно, но не компенсирует слабую тему.

## Mainpointschema (до текста)

1. Инфополе → 2. Главное для читателя → 3. Формат → 4. Заголовок → 5. Структура → 6. Фактура → 7. Текст → 8. Сокращение + лид

## Заголовок

| Критерий | Порог |
|----------|-------|
| Длина | 7–8 слов, макс. 15 |
| Соответствие | 100% тексту |
| Структура | художественная часть : пояснение с ключевыми словами |

## Оформление

| Метрика | Норма |
|---------|-------|
| Доскрол | 60%+ (отлично 85%+) |
| Прочтения | ~30–35% |
| Потери на участке | >10% — разбирать причину |

**Жёсткое правило:** нет экранов голого текста. Подзаголовок = вывод/факт.

## Изображения

| Делать | Не делать |
|--------|-----------|
| Свои фото рабочего места, скриншоты | Фотосток «успешный успех» |
| Подпись с фактом | Картинка «для красоты» |
| КДПВ с приростом ~20–30% просмотров | Мутные, «корпоративный» единый стиль |

## Перед публикацией

1. Фактчек: даты, имена, цитаты, термины
2. «К чему придерётся читатель?»
3. Ссылки на первоисточники для спорного
4. Лид — после текста, не дублирует заголовок

## Время публикации

- Рост чтений: с ночи к вечеру; чт–вс выше вт–ср
- Разброс по неделе ~39%, по суткам ~20%
- **Если тема слабая — слот не спасёт**
- Пт вечер — развлекательный контент; серьёзная статья может проиграть

## Комментарии

- Уважение к оппоненту
- Ошибку признать спокойно, поблагодарить
- Эмоции → пауза 10 минут
- Не минусовать личность (карма)
